# Student Study Material Portal

A web-based Java project that helps students upload and manage study materials.

## Features

- User Registration

- User Login

- Upload Study Materials

- View Uploaded Files

- Delete Materials

## Technologies Used

- Java

- JSP

- Servlet

- MySQL

- HTML

- CSS

- Apache Tomcat
